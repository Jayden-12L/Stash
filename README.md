# Stash

A beautiful visual library for everything worth keeping.

## Run locally

    npm install
    npm run dev

## Current features

- Visual masonry library with curated starter content
- Search across saved items
- Quick Save modal for links and notes
- Collections and category navigation
- Favorites and item detail views
- Remove saved items
- Light and dark themes
- Responsive desktop and mobile layout
- Browser-local persistence with localStorage

Stash is a separate project from Daydiary. Native iOS share and keyboard extensions are planned as a later phase.
